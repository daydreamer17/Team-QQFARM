# QuoteWise 界面文案中英字典

本文档按页面和公共组件整理当前系统的用户可见文案。它是后续建立前端语言包和翻译后端用户可见消息的基准。专业名词以《01_系统中英术语字典》为准，程序状态以《03_状态与枚举字典》为准。

动态内容使用 `{placeholder}` 表示。实现时保留变量，不要拼接依赖中英文语序的句子。
