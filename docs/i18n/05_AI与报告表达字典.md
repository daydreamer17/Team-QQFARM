# QuoteWise AI 与报告中英表达参考

本文档为 AI 决策助手、调查结果和采购总结提供自然英文参考。它不是固定句库，模型可以根据上下文自然表达；但事实、状态、引用和采购权限边界必须保持准确。专业名词以《01_系统中英术语字典》为准。

| 输入提示 | 可以询问推荐原因，也可以描述希望模拟的条件。 | Ask about the recommendation or describe the conditions you would like to simulate. |

## 翻译原则

1. 英文可以自然改写，不要求逐字对应中文句序。
2. 金额、日期、数量、供应商名称和引用必须与冻结事实一致。
3. `Pending`、`Failed`、`Review Required` 和 `Not Evaluated` 不得互相替换。
4. 推荐使用 `recommend`，只有正式人工授权才使用 `approve`。
5. 缺少材料不自动等于不合规；只有确定性检查为 `FAIL` 时才写 `non-compliant`。
6. 建议沟通内容始终是草稿，不得暗示系统已经联系供应商。
7. AI 回答正文使用 `[1]`、`[2]` 等简短标号，完整引用 ID 放在回答底部。
