# QuoteWise 字段名称中英字典

本文档定义结构化字段在界面、API 文档和报告中的英文显示名称。代码字段名、JSON Key 和数据库列名保持不变。报价审核字段以 `data/contracts/quote_data_field.csv` 和 `GET /api/v1/quote-field-schema` 为权威来源。

## 采购需求字段

| 字段名 | 中文显示 | 标准英文 | 使用说明 |
|---|---|---|---|
| `task_name` | 任务名称 | Task Name | 用户可识别的采购任务名称 |
| `scenario_id` | 场景编号 | Scenario ID | 外部或演示场景标识；不是 Decision Scenario ID |
| `manufacturer` | 制造商 | Manufacturer | 采购目标产品的制造商 |
| `manufacturer_part_number` | 制造商料号 | Manufacturer Part Number | 制造商定义的产品编号 |
| `package` | 封装 | Package | 器件本体封装 |
| `revision` | 物料版本 | Item Revision | 产品规格修订，不是任务或文件版本 |
| `condition` | 物料状态 | Item Condition | 全新、翻新或二手 |
| `allow_substitutes` | 允许替代料 | Allow Substitutes | 是否接受替代产品 |
| `base_unit` | 采购计量单位 | Procurement Unit | 需求和计算使用的基础单位 |
| `required_quantity` | 需求数量 | Required Quantity | 用户计划采购的基础数量 |
| `quantity_unit` | 数量单位 | Quantity Unit | 需求数量的单位 |
| `budget_amount` | 预算金额 | Budget Amount | 使用十进制字符串传输 |
| `currency` | 币种 | Currency | 需求预算币种 |
| `includes_shipping` | 预算包含运费 | Budget Includes Shipping | 预算口径是否包含运费 |
| `tax_mode` | 税费比较口径 | Tax Treatment | 含税、未税或不适用 |
| `other_fees_required` | 要求计入其他费用 | Include Other Fees | 是否要求其他费用进入比较 |
| `planned_order_date` | 计划下单日期 | Planned Order Date | 可为空的预计下单日期 |
| `delivery_deadline` | 交付截止日期 | Delivery Deadline | 最晚允许到货日期 |
| `delivery_location` | 交付地点 | Delivery Location | 货物要求送达的位置 |
| `ranking_preference` | 主要排序偏好 | Primary Ranking Criterion | 兼容接口中的主排序字段 |
| `secondary_preference` | 次要排序偏好 | Secondary Ranking Criterion | 兼容接口中的次排序字段 |

## 报价审核字段：身份

> 以下 30 个字段是当前人工审核范围。`supplier_id` 由后端建立或核对，不属于 30 个可编辑报价字段。

| 字段名 | 中文显示 | 标准英文 | 使用说明 |
|---|---|---|---|
| `supplier_name` | 供应商名称 | Supplier Name | 出具报价的供应商正式名称 |
| `supplier_country` | 供应商所在国家 | Supplier Country | 不用于推断币种、税费或运费 |

## 报价审核字段：规格

| 字段名 | 中文显示 | 标准英文 | 使用说明 |
|---|---|---|---|
| `category` | 采购类别 | Procurement Category | 类别标签，不作为精确器件匹配依据 |
| `item` | 商品名称 | Item Description | 报价中的商品目录名称或描述 |
| `manufacturer` | 制造商 | Manufacturer | 供应商不能默认等于制造商 |
| `manufacturer_part_number` | 制造商料号 | Manufacturer Part Number | 不得用供应商 SKU 模糊替代 |
| `package` | 封装 | Package | 器件本体封装，不是销售包装 |
| `revision` | 物料版本 | Item Revision | 不得与报价版本或文件版本混淆 |
| `condition` | 物料状态 | Item Condition | `NEW`、`REFURBISHED` 或 `USED` |
