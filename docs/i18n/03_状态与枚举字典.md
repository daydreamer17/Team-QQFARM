# QuoteWise 状态与枚举中英字典

本文档规定 API、数据库和工作流枚举在中英文界面中的显示方式。**程序值不得翻译或改名**；翻译只作用于用户可见标签。相同程序值在不同业务对象中可以使用不同显示文字，例如任务的 `PENDING` 显示为 “Pending”，Summary 的 `PENDING` 显示为 “Queued for Generation”。

## 任务状态

| 程序值 | 中文显示 | 英文显示 | 使用说明 |
|---|---|---|---|
| `DRAFT` | 草稿 | Draft | 任务已经创建，但尚未开始完整分析 |
| `READY` | 待分析 | Ready for Analysis | 输入已准备好 |
| `QUEUED` | 等待处理 | Queued | 已创建后台 Job |
| `RUNNING` | 分析中 | Analysing | Worker 正在执行工作流 |
| `NEEDS_INPUT` | 需要确认 | Action Required | 工作流中断并等待用户输入 |
| `COMPLETED` | 已完成 | Completed | 当前任务修订已完成 |
| `FAILED` | 处理失败 | Failed | 当前运行失败 |
| `ABANDONED` | 已废弃 | Abandoned | 不可恢复，历史记录保持可读 |
