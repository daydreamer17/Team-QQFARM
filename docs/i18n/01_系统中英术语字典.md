# QuoteWise 系统中英术语字典

本文档定义 QuoteWise 用户界面、后端用户可见消息、AI 助手和采购总结共同使用的标准英文术语。完整句子见《02_界面文案字典》，程序状态值见《03_状态与枚举字典》，结构化字段见《04_字段名称字典》。
