## Generation provenance

Created on 2026-10-08 with the built-in `image_gen` tool (reference-guided generation; no CLI/API fallback). The references were the project's existing procurement owl and procurement panorama. Final generated outputs were copied without alteration; SVG badges were authored directly as vectors. Screenshots were reused from the poster assets, not generated.

Create a square compact emblem of this same friendly mint-teal owl with cream face, oversized round navy spectacles, navy waistcoat and pale yellow tie. One small green checkmark on a cream document held at the lower right, no detailed clipboard list. Center in a pale sky-blue circular medallion with a thin navy outline; actual transparent pixels outside the circle. Warm, cheerful, clean hand-illustrated cartoon style matching the reference. Palette navy #102A43, teal #236C69, mint, cream #FCFBF5, soft gold #FFF0BA. No text, no letters, no watermark, no additional characters, no scenery. Generous 8% transparent edge margin.

Beneath that, one prominent cream-and-gold rounded play-button shape with a navy play triangle and exact words "WATCH THE DEMO". Tiny "QuoteWise" wordmark at upper right. No fake application screens, no QR code, no metrics, no YouTube logo, no watermark.
